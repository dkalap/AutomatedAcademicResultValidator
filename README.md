# Automated Academic Result Validator

A Java-based system to manage and validate student academic results using OOP principles.

## Features
- Calculate total marks and percentage
- Determine Pass/Fail status based on subject-wise cutoff
- Grade assignment (A+, A, B, C, D)
- 5 automated JUnit test cases to validate result logic

## Technologies Used
- Java (Core Java, OOP)
- JUnit 4.13.2 (Unit Testing / Test Automation)
- Git & GitHub

## How to Run
1. Compile: `javac Student.java Result.java Main.java`
2. Run: `java Main`

## Test Results
All 5 JUnit tests passed successfully.
- Total marks calculation test
- Pass status validation test
- Fail status validation test  
- Percentage calculation test
- Grade assignment test
